# 0.0.1-rc.1 — experimental testing prerelease

This is an early migration snapshot for testing, not a declaration of original-mod parity or a stable release. Use a new disposable world; do not open valuable saves. Legacy worlds and cross-version/cross-loader save conversion are unsupported.

## Installation

Install exactly one production JAR matching Minecraft and loader. Do not install `-sources.jar` files. Install external dependencies separately on client and server:

| Minecraft | Loader tested | Required dependencies |
| --- | --- | --- |
| 1.20.1 | Fabric Loader 0.17.2 | Fabric API 0.92.6+1.20.1; Patchouli 1.20.1-85-FABRIC |
| 1.20.1 | Forge 47.3.39 | Patchouli 1.20.1-85-FORGE |
| 1.21.1 | Fabric Loader 0.17.2 | Fabric API 0.116.12+1.21.1; Patchouli 1.21.1-93-FABRIC |
| 1.21.1 | NeoForge 21.1.234 | Patchouli 1.21.1-93-NEOFORGE |

Minecraft 1.20.1 uses Java 17; Minecraft 1.21.1 uses Java 21.
Optional wearable support: Trinkets 3.7.2 / 3.10.0 on the respective Fabric versions (including its required dependencies), or Curios 5.14.1+1.20.1 / 9.5.1+1.21.1 on Forge/NeoForge. These libraries are not bundled.

## What to test

- Quartz acquisition and Gem Cutter recipes, counted ingredients, shift-click and crafting remainders.
- Radiant storage insertion/extraction, upgrades, portable contents and save/restart conservation.
- Scepters, gems, recharge, sockets, keybinds and HUD.
- Block/item models, hand transforms, tooltips and physical mining.
- Multiplayer permissions, synchronization and shared storage, using disposable test data.

Report the exact JAR/loader, reproduction steps, expected/actual result and relevant log excerpt. For duplication or loss, include item counts before and after, participants and restart behavior. Never attach credentials or private server data.

## Known limitations

- The full Tome of Arcana content, registered item, crafting and automatic acquisition are unfinished. Its Gem Cutter page adapter is infrastructure only, not an available complete guidebook.
- Remaining reachable upstream behavior still requires source-inventory reconciliation; not every feature is complete.
- Radiant Furnace is deliberately excluded. Independent Echo support remains, without invented furnace acquisition or duplication machinery.
- Registered unfinished upstream devices remain prototypes; their tooltip promises do not imply working machinery.
- Connected-player rendering/input, mod compatibility and broader multiplayer acceptance are incomplete. Passing build/native assertions and startup fixtures is not complete gameplay verification.
- The isolated Fabric Tome probe confirmed scaled input/output tooltips; its last client timed out, so that session does not establish graceful shutdown or world-save acceptance.

## Releasing through Gradle

Maintainers need authenticated `gh`, git, Python 3.11+ and the project's Java/Gradle toolchains. Set the version in `stonecutter.properties.toml`, add matching release notes, commit all project changes, and push the commit and matching tag before publishing.

Run `./gradlew publishGithub --no-daemon` with the timeout/full-log capture convention from `AGENTS.md`. This task builds/tests all four leaves, runs the artifact verifier, requires a clean tree and a pushed tag identifying HEAD, generates SHA256SUMS, and creates a GitHub prerelease using `gh` as transport. It refuses to overwrite existing releases and reads back asset names/sizes. It does not publish to Modrinth, CurseForge or Maven.

Assets: four production JARs, four source JARs and SHA256SUMS. This is a testing prerelease and is not marked as the latest stable release.
