# 0.0.1

First numbered release of Arcane Archives Recrafted for Minecraft 1.20.1 (Fabric/Forge) and 1.21.1 (Fabric/NeoForge).

The migration is still incomplete. This version number does not claim full upstream parity or production-world safety. Use disposable worlds; legacy worlds and cross-version/cross-loader save conversion are unsupported.

## Changes since 0.0.1-rc.1

- Expanded Gem Cutter crafting, synchronization, ownership and conservation verification.
- Added Radiant Crafting Table transfer/workstation support and Resonator information in JEI/EMI; restored upstream viewer item exclusions.
- Replaced anonymous Minecraft subclasses that blocked clean Forge compilation.
- Routed Sliver Smashing assertions through the native Forge loader rather than the incompatible duplicate standalone runner.
- Added four-target CI and plugin-based GitHub, CurseForge and Modrinth publishing configuration.

## Installation

Install exactly one production JAR matching your Minecraft version and loader. Do not install `-sources.jar` files. External dependencies are required separately on both client and server:

| Minecraft | Loader | Required dependencies |
| --- | --- | --- |
| 1.20.1 | Fabric Loader 0.17.2 | Fabric API 0.92.6+1.20.1; Patchouli 1.20.1-85-FABRIC |
| 1.20.1 | Forge 47.3.39 | Patchouli 1.20.1-85-FORGE |
| 1.21.1 | Fabric Loader 0.17.2 | Fabric API 0.116.12+1.21.1; Patchouli 1.21.1-93-FABRIC |
| 1.21.1 | NeoForge 21.1.234 | Patchouli 1.21.1-93-NEOFORGE |

Use Java 17 for Minecraft 1.20.1 and Java 21 for Minecraft 1.21.1.
Optional wearable support uses Trinkets 3.7.2 / 3.10.0 on Fabric, or Curios 5.14.1+1.20.1 / 9.5.1+1.21.1 on Forge/NeoForge. Dependencies are not bundled.

## Known limitations

- The complete Tome of Arcana content, item and acquisition remain unfinished.
- Radiant Furnace is intentionally excluded. Unfinished upstream device prototypes do not imply working machinery.
- Remaining upstream behavior, connected-client rendering/input, integrations and multiplayer acceptance are incomplete.
- Combined JEI/EMI tag-recipe collisions remain a known limitation.
- Gem Cutter retains the original fixed-size layout; undersized windows/high GUI scales can clip it.

Please report exact JAR/loader versions, reproduction steps and relevant logs. For item loss or duplication, include counts before and after, participants and restart behavior. Never attach credentials or private server data.

GitHub assets include four production JARs, four source JARs and SHA256SUMS. Publishing configuration does not imply this release is available on CurseForge or Modrinth.
