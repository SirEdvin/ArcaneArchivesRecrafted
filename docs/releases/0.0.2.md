# 0.0.2 — Connected Storage and Tome of Arcana

**Gameplay testing release.** Published at the user's request for initial testing. Automated builds/native tests pass; graphical, connected multiplayer and real save/restart acceptance remain incomplete. Use a fresh disposable world and report issues; this is not a claim of complete upstream parity.

## Highlights

- Connected storage discovery, server-authoritative Manifest browsing, search/sorting, location tracking, lectern access and Trove HUD presentation.
- Brazier of Hoarding acquisition, routing, player deposits, configuration, automation and range presentation, with current-eligibility and item-conservation guards.
- Complete conversion of the audited Tome into Patchouli categories, entries, conditional content, illustrations and live recipe displays. Acquisition includes the configured bookshelf/Resonator routes and ordinary crafting.
- Restored both original Radiant Chest crafting recipes.
- Manifest hover-item tracking from inventory slots and optional JEI; holding Shift retains the screen after a successful selection.
- Restored per-player Trove withdrawal preference and default Chest routing preference. Existing saved routing is preserved.
- Amphora runtime fluid presentation, using the existing item-render hook.

## Compatibility and intentional scope

- Minecraft 1.20.1: Fabric and Forge. Minecraft 1.21.1: Fabric and NeoForge.
- Patchouli is an external required dependency, not bundled. Use the exact loader/version requirements in the packaged mod metadata. JEI remains optional; hover-slot tracking does not require it. Other optional integrations retain their documented per-target limitations.
- Fresh worlds only. This is not an importer for original Minecraft 1.12 saves.
- Original unfinished content remains unfinished. The Tome identifies original incomplete topics explicitly rather than inventing machine functions. Radiant Furnace remains excluded under the approved scope decision.
- Previously deferred copied-Amphora-item behavior is unchanged.
- Native Patchouli layout replaces the legacy Guidebook layout. Navigation repairs, unavailable legacy references and presentation differences are documented in behavior records 0148, 0150 and 0151.
- `TrovesDispense=true` follows the original implementation: ordinary click withdraws one item, sneaking withdraws a stack. False reverses the clicks. The legacy configuration comment described the opposite behavior.

## Verification and remaining release gates

The [implementation checkpoint](../migration/0.0.2-IMPLEMENTATION_CHECKPOINT.md) records exact commands, logs, local JAR paths/checksums, four-target native suites, separate clean/build, Stonecutter restoration and artifact checks. All 25 script tests pass.

Before release acceptance: user-first graphical gameplay; Tome layout/navigation and resource reload; connected multiplayer/preferences/hover input; actual save/restart/reconnect; applicable optional-integration/reload and sound acceptance. Compilation, native server fixtures and artifact inspection do not establish those behaviors.

The user authorized the 0.0.2 version bump, commit, push, tag and GitHub publication for testing. Publication on other distribution platforms is not part of this release.
